# one-sentence-1800

A single English sentence that explains the modern internet to a traveler from 1800, using one harbour scene: ships sail out carrying word and sail home again carrying word from far lands. Every word in the sentence was checked against a pre-1800 vocabulary list, so the picture is built only from things a person of that time could already imagine — a harbour, ships, sails, and word carried across the sea.
